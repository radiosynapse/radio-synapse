Architecture Globale & Réseau Docker

L'infrastructure Radio Synapse s'articule autour d'un réseau Docker unifié (synapse-net) permettant la communication interne haute performance entre la base de données, les flux audio et le proxy inverse.

// Schéma du flux réseau :
Internet (Auditeurs / DJ / Navigateurs)
  │
  ▼ Ports 80 & 443 (HTTPS / SSL Let's Encrypt)
[ NGINX PROXY MANAGER (npm) ] ── (Réseau bridge : synapse-net)
  ├──► db.radiosynapse.fr ──► [ Supabase Kong API Gateway :8000 ]
  │                           ├── PostgREST (REST API :3000)
  │                           ├── GoTrue (Auth :9999)
  │                           └── Realtime (WebSockets :4000)
  ├──► stream.radiosynapse.fr ──► [ Icecast 2 Audio Server :8000 ]
  │                           ▲ Sources audio internes
  │                           └── [ Liquidsoap Regie :8572 & Harbor :8005 ]
  └──► npm.radiosynapse.fr ──► [ NPM Web UI Admin :81 ]

Prérequis & Installation Docker sur le VPS

Connectez-vous à votre VPS en SSH avec un compte disposant des droits sudo (ex: Ubuntu 22.04 / 24.04 ou Debian 12).

1. Mise à jour du système & Installation universelle de Docker : 
sudo apt-get update && sudo apt-get upgrade -y
sudo apt-get install -y curl wget git ufw htop jq net-tools ca-certificates gnupg lsb-release

# Installation Docker universelle (compatible Debian 12/13 Trixie & Ubuntu)
curl -fsSL https://get.docker.com | sudo sh

# Création du réseau Docker commun
sudo docker network create synapse-net
2. Configuration du Pare-feu UFW : 
sudo ufw allow 22/tcp    # SSH
sudo ufw allow 80/tcp    # HTTP Let's Encrypt (NPM)
sudo ufw allow 443/tcp   # HTTPS SSL (NPM)
sudo ufw allow 81/tcp    # Admin Nginx Proxy Manager
sudo ufw allow 8000/tcp  # Icecast (Radio master)
sudo ufw allow 8005/tcp  # Direct DJ Harbor (Liquidsoap)
sudo ufw enable

Déploiement de Supabase Self-Hosted

Supabase fournit l'authentification (GoTrue), l'API REST temps réel (PostgREST), les WebSockets (Realtime) et le moteur de base de données PostgreSQL 15.

1. Cloner et configurer Supabase Docker : 
# Répertoire de travail
sudo mkdir -p /opt/synapse-infra
cd /opt/synapse-infra

# Cloner le dépôt officiel Supabase Docker
sudo git clone --depth 1 https://github.com/supabase/supabase
cd supabase/docker

# Copier le fichier d'environnement modèle
sudo cp .env.example .env

# Attacher Supabase au réseau commun synapse-net
echo "
networks:
  default:
    name: synapse-net
    external: true
" | sudo tee -a docker-compose.yml
2. Lancer Supabase et exécuter le schéma SQL : 
# Démarrage des conteneurs Supabase
sudo docker compose up -d

# Téléchargement du schéma Radio Synapse et injection directe dans PostgreSQL
curl -fsSL https://raw.githubusercontent.com/radio-synapse/schema/main/supabase_schema.sql -o /tmp/schema.sql 2>/dev/null || true
# Ou collez directement le contenu de public/supabase_schema.sql dans le Supabase Studio (http://IP_VPS:8000/project/default/sql)

Déploiement du Serveur Icecast 2

Icecast 2 distribue les flux audio encodés vers les lecteurs web des auditeurs.

Créer le conteneur Icecast 2 dans synapse-net : 
sudo mkdir -p /opt/synapse-infra/icecast
cd /opt/synapse-infra/icecast

cat << 'EOF' | sudo tee docker-compose.yml
version: '3.8'

services:
  icecast:
    image: plribeiro3000/icecast:latest
    container_name: synapse-icecast
    restart: always
    environment:
      - ICECAST_SOURCE_PASSWORD=synapse_icecast_source
      - ICECAST_ADMIN_PASSWORD=synapse_icecast_admin
      - ICECAST_PASSWORD=synapse_icecast_hackme
      - ICECAST_RELAY_PASSWORD=synapse_icecast_relay
      - ICECAST_ADMIN_USERNAME=admin
      - ICECAST_ADMIN_EMAIL=admin@radiosynapse.fr
      - ICECAST_LOCATION=France
    ports:
      - "8000:8000"
    networks:
      - synapse-net

networks:
  synapse-net:
    external: true
EOF

sudo docker compose up -d

Déploiement de Liquidsoap (AutoDJ, Harbor DJ & Encodage)

Liquidsoap gère la lecture des playlists, les crossfades intelligents, la prise d'antenne DJ en direct (port Harbor 8005) et l'encodage MP3/AAC vers Icecast.

Créer le script Liquidsoap et le conteneur Docker : 
sudo mkdir -p /opt/synapse-infra/liquidsoap/media
cd /opt/synapse-infra/liquidsoap

# Script de diffusion multi-stations
cat << 'EOF' | sudo tee radio.liq
set("log.level", 3)
set("server.telnet", true)
set("server.telnet.bind_addr", "0.0.0.0")
set("server.telnet.port", 8572)

# Harbor Live Input pour prise d'antenne DJ
live_dj = input.harbor("/live", port=8005, password="synapse_dj_live_pass")

# AutoDJ Playlist locale
autodj = playlist(reload_mode="watch", "/music")
fallback_track = single("/music/fallback.mp3")

# Sélecteur dynamique avec transition douce
radio_source = fallback(track_sensitive=false, [live_dj, autodj, fallback_track])
radio_source = crossfade(duration=3.5, radio_source)

# Sortie vers Icecast (synapse-icecast dans le réseau Docker)
output.icecast(%mp3(bitrate=320, samplerate=44100),
  host="synapse-icecast", port=8000,
  password="synapse_icecast_source",
  mount="/synapse_hd.mp3",
  name="Radio Synapse HD",
  genre="Electro, Synthwave, Pop",
  url="https://radiosynapse.fr",
  radio_source)
EOF

# Compose Liquidsoap
cat << 'EOF' | sudo tee docker-compose.yml
version: '3.8'

services:
  liquidsoap:
    image: savonet/liquidsoap:v2.2.5
    container_name: synapse-liquidsoap
    restart: always
    volumes:
      - ./radio.liq:/etc/liquidsoap/radio.liq:ro
      - ./media:/music:rw
    ports:
      - "8005:8005"
      - "8572:8572"
    command: ["liquidsoap", "/etc/liquidsoap/radio.liq"]
    networks:
      - synapse-net

networks:
  synapse-net:
    external: true
EOF

sudo docker compose up -d

Déploiement de Nginx Proxy Manager & SSL

Nginx Proxy Manager gère le routage de vos sous-domaines vers les bons conteneurs internes et renouvelle automatiquement vos certificats SSL Let's Encrypt.

Installer Nginx Proxy Manager : 
sudo mkdir -p /opt/synapse-infra/npm
cd /opt/synapse-infra/npm

cat << 'EOF' | sudo tee docker-compose.yml
version: '3.8'

services:
  npm:
    image: 'jc21/nginx-proxy-manager:latest'
    container_name: synapse-npm
    restart: unless-stopped
    ports:
      - '80:80'
      - '81:81'
      - '443:443'
    volumes:
      - ./data:/data
      - ./letsencrypt:/etc/letsencrypt
    networks:
      - synapse-net

networks:
  synapse-net:
    external: true
EOF

sudo docker compose up -d
Configuration des Proxy Hosts dans NPM (http://VOTRE_IP:81) :
  • db.radiosynapse.fr ➔ Forward Host : supabase-kong, Port : 8000, Activer WebSockets Support & SSL Let's Encrypt.
  • stream.radiosynapse.fr ➔ Forward Host : synapse-icecast, Port : 8000, Activer SSL Let's Encrypt & Custom Nginx Header (proxy_buffering off;).

Manuel & Tutoriel d'Utilisation du Panel Admin

Régie Liquidsoap & Diffusion

Supervisez les montages Icecast, l'encodage actif (MP3/AAC), les auditeurs connectés et le statut du serveur de streaming. En cas d'intervention en direct, le studio WebDJ se connecte directement au port Harbor 8005.

Stations Radio

Ajoutez, éditez ou réordonnez les stations radio diffusées sur l'application. Chaque station dispose d'une URL de flux Icecast, d'une couleur d'ambiance et d'un genre musical.

Programmation & Grille Antenne

Planifiez les émissions, les playlists automatiques et les résidences DJ par créneaux horaires. Les changements sont répercutés en temps réel dans l'agenda public des auditeurs.

Utilisateurs & Rôles

Gérez les auditeurs, animateurs, administrateurs et super-administrateurs. Associez les identifiants DJ Harbor aux animateurs pour leur permettre d'émettre en direct depuis leur console.

Défis, Quêtes & Modération

Créez des défis auditeurs (proposer une musique, quiz en direct, temps d'écoute). Modérez les propositions de morceaux et créditez automatiquement les points aux gagnants.

Feature Flags & Modules

Activez ou désactivez instantanément les fonctionnalités du lecteur (chat en direct, visualiseur audio 3D, égaliseur, métadonnées enrichies) sans redémarrer le serveur.
