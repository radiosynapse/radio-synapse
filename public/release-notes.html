01

Direction Artistique, Châssis & Extraction Chromatique

Radio Synapse repose sur une identité visuelle Cyber-Analogique & Rétro-Futuriste Japonaise rigoureusement calquée sur les lecteurs Sony NetMD / Walkman MZ Series (1998–2003). L'ergonomie combine la nostalgie mécanique du support physique MiniDisc avec la fluidité des applications modernes de streaming.

1.1 Le Châssis Proportionnel 390px × 710px & Moteur d'Échelle

Pour garantir un rendu au pixel près sans rupture de mise en page, l'interface principale est confinée dans un châssis mobile de référence de 390px × 710px. Le composant racine App.tsx embarque un moteur de calcul d'échelle dynamique (viewportScale) : 

// Calcul de mise à l'échelle automatique dans App.tsx
const scaleW = windowWidth / 390;
const scaleH = windowHeight / 710;
const viewportScale = Math.min(Math.max(Math.min(scaleW, scaleH), 0.65), 1.35);

Ce facteur ajuste dynamiquement l'application de 0.65x (sur petits smartphones) jusqu'à 1.35x (sur consoles Hi-Fi et grands écrans desktop), maintenant des proportions absolues.

1.2 Extraction Chromatique en Temps Réel (Canvas 2D)

L'application n'utilise pas de couleur statique : src/utils/coverColorExtractor.ts analyse en temps réel la pochette de l'album diffusé via un Canvas HTML5 2D invisible :

  • Couleur Primaire (Accent Principal) : Utilisée pour le rétroéclairage néon du boîtier MiniDisc, la bordure lumineuse du potentiomètre Play/Pause, les jauges de scrubbing et les voyants On-Air.
  • Couleur Secondaire (Accent Complémentaire) : Utilisée pour les typographies d'artistes en monospace, les icônes de contrôle et les halos lumineux d'arrière-plan.

1.3 Arrière-Plan Vivant Multicouche

L'ambiance visuelle superpose 3 couches : la pochette de l'album floutée à blur(85px) avec transition fluide en fondu enchaîné (Crossfade), surmontée d'un voile noir semi-transparent #040406/80 et d'un vignettage radial simulant la profondeur d'un meuble de studio audio.

07

Architecture Supabase PostgreSQL & Realtime (Tables & RLS)

Règles de Sécurité RLS et Abonnements Realtime
Toutes les tables bénéficient du Row Level Security (RLS) avec politiques de lecture publique et modifications restreintes aux administrateurs. Les mutations sur les stations et les dédicaces sont propagées en WebSocket Realtime à tous les auditeurs connectés sans nécessiter de rafraîchissement manuel.
Nom Table PostgreSQL Clé Primaire Realtime Description & Rôle Métier
synapse_stations id (TEXT) Actif (REPLICA FULL) Configuration des radios, noms, descriptions, couleurs néon, URLs Icecast et métadonnées.
synapse_messages id (TEXT) Actif (REPLICA FULL) Dédicaces en direct et formulaires de contact auditeurs avec statut de modération instantanée.
synapse_events id (TEXT) Actif (REPLICA FULL) Événements clubbing, concerts, émissions résidents et billetteries.
synapse_promotions id (TEXT) Actif (REPLICA FULL) Codes promo et réductions partenaires négociées pour les auditeurs.
synapse_challenges id (TEXT) Actif (REPLICA FULL) Gamification : quêtes journalières, XP, badges et paliers de fidélité.
synapse_admin_data key (TEXT) Actif (REPLICA FULL) Store K/V sécurisé pour drops audio, profils de rôles RBAC, personnalisations et presets.
user_synapse_data id (TEXT) Inactif Coups de cœur (Likes / Super-likes) synchronisés par compte utilisateur.

7.1 Procédure de Déploiement VPS Supabase

  1. Exécuter le script automatisé sur votre VPS : sudo bash /public/setup-vps-stack.sh.
  2. Accéder à Supabase Studio sur http://VOTRE_IP:54323 (ou via votre sous-domaine api.radiosynapse.fr).
  3. Ouvrir l'onglet SQL Editor et coller le script SQL fourni dans le Panel Admin (bouton Copier le script SQL).
  4. Exécuter le script pour créer automatiquement toutes les tables, les index et activer le Realtime PostgreSQL.
